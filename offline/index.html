Download the offline edition

The file is generated from the same source as the online workbench on every deployment.

What works from file://: opening and analysing a local audio or video file (live or whole-file), the internal test tone, the self-test, CSV/JSON/PNG export, keyboard shortcuts.

What needs a local server: microphone and tab capture. Browsers treat file:// as an insecure origin and block capture APIs. The page will tell you this and stays usable for files.

Run it from a folder

If you want microphone access without deploying the site, serve the folder locally:

python3 -m http.server 8000
# then open http://localhost:8000/app/

The standalone file can also be served this way; capture works from localhost.

Why offer a single file?

Because “local” should survive the website. A single file is easy to inspect, easy to keep, and cannot phone home even if someone wanted it to. The code in it is the same code the hosted page runs.

Prefer the hosted version?

It adds deep links, saved preferences and the guides.
