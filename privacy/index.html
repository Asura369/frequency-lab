Privacy

Your audio does not leave the browser

Frequency Lab is a static website. The microphone, tab capture and file decoding all run in your browser, and there is no server-side analysis to send audio to.

What is processed, and where

Microphone samples arrive through getUserMedia, tab audio through getDisplayMedia, and files through the browser’s own decoder. All of it goes into a Web Audio graph in the page. The analysis buffers exist in memory only and are discarded when you press Stop or close the tab.

Nothing is uploaded. There is no recording, no clip storage and no request that carries audio or measurements. File object URLs are revoked when a session ends.

What is stored

Two things can persist on your device:

  • Preferences in localStorage under freqlab.settings.v1: the last target frequency, tolerance and plot palette. No audio, no identifiers.
  • Saved files you exported yourself (CSV or PNG), wherever your browser puts downloads.

Clearing site data removes the preferences. The site works without them.

No tracking, no accounts

There are no accounts, no cookies, no analytics scripts and no third-party embeds. No fonts, scripts or images are loaded from another origin. You can verify this in the network panel: every request goes to this site.

If you install the site as an app, its service worker caches the interface files on your device for offline use. That cache contains no audio and no personal data.

The site is served by a static host, which keeps ordinary request logs (IP address, user agent, requested path) for operational and abuse purposes, as any web server does. Those logs do not contain audio.

Permissions

Microphone and tab capture are requested only when you press the corresponding button, and they require a secure context (HTTPS or localhost). The browser shows its own capture indicator while a session is live. Stop releases the tracks immediately.

Clipboard

“Copy setup link” and “Copy summary” write text to your clipboard only after you press them. The setup link contains the target frequency and tolerance — no measurements, no identifiers.

Contact

This is an independent project. A contact address will be published with the launch domain; until then, the site makes no promises it cannot keep about support.
